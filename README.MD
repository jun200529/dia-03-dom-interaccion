# Día 3 - Interacción con DOM 

## Objetivo

Aprender a conectar JavaScript con HTML usando el DOM y eventos.

---

## Lo que aprendí

- document.getElementById()
- addEventListener()
- textContent
- Manipulación básica del DOM
- Eventos con botones

---

## Proyecto realizado

Creé una página interactiva donde un botón cambia dinámicamente el texto usando JavaScript.

---

## Tecnologías utilizadas

- HTML
- CSS
- JavaScript

---

## Resultado

Al hacer click en el botón, el contenido de la página cambia dinámicamente.

---
